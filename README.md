# Bee arR Graphix

Modern, responsive photography, videography and drone services website for
**Bee arR Graphix** — built with React, Vite and Tailwind CSS.

Premium dark charcoal/black visual style with gold (studio/wedding) and
electric-sky (aerial drone) accent colors, since drone photography &
videography is one of the most requested services.

## Stack

- [React 19](https://react.dev/)
- [Vite](https://vite.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Framer Motion](https://motion.dev/) for animation
- [lucide-react](https://lucide.dev/) for icons

## Getting started

```bash
npm install
npm run dev
```

## Project structure

```
src/
  components/   Reusable UI pieces (Navbar, Logo, background decorations)
  sections/     Page sections composed in App.jsx (Hero, ...)
  data/         Static content (nav links, services, etc.)
```
